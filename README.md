# Bright Future Course Website

Welcome to the Bright Future Course Website — a modern, responsive platform designed to help students and professionals access quality education from anywhere. This project is a demonstration of an educational website built with pure HTML and CSS, offering a wide range of courses and a smooth user experience.

## 🌟 Features

- **Responsive Design**: Fully adaptable layout for desktops, tablets, and mobiles with clean, attractive visuals.
- **Modern Home Page**: Eye-catching hero section with a call-to-action button to start learning immediately.
- **Course Listings**: Detailed course cards for subjects like Web Development, Leadership, Hacking, Finance, Graphic Designing, Artificial Intelligence, Robotics, and Data Analysis. Each card includes images, short descriptions, prices, ratings, and expandable details.
- **Student Testimonials**: Realistic feedback from students to build trust and credibility.
- **About Us Section**: Highlights the organization's mission, vision, team, success stories, and invitation to join the community.
- **Registration Form**: Simple and intuitive form for new users to register and select courses.
- **Contact Form**: Easy way for users to reach out with their queries.
- **Modern Footer**: Quick access links and creator credit.

## 🛠️ Tech Stack

- **HTML5** (Structure)
- **CSS3** (Styling, layout, responsiveness)
- **No JavaScript** (All interactivity is handled via CSS and HTML attributes)

## 📁 Project Structure

- `index.html` — Main HTML file containing all website sections: header, hero, courses, testimonials, about, registration, contact, and footer.
- `style.css` — All custom styles for layout, responsiveness, and visual effects.
- `assets/` — Folder for images (e.g., logo, course images, testimonial avatars).

## ✨ Section-wise Overview

### 1. Header & Navigation

- Sticky navigation bar with logo and menu links for smooth scrolling to different sections.

### 2. Hero Section

- Catchy headline and tagline with a prominent “Start A Course” button and a hero image.

### 3. Courses Section

- Grid of course cards, each showing:
  - Course image, title, summary, price, rating (star icons)
  - “Learn More” button reveals more details about the course

### 4. Testimonials

- Grid layout with student photos, names, reviews, and star ratings.

### 5. About Us

- Six cards explaining the mission, vision, team, testimonials, success stories, and an invitation to join.

### 6. Registration

- User-friendly registration form:
  - Name, Email, Password, Course selection (dropdown), Register button

### 7. Contact

- Simple contact form for user queries.

### 8. Footer

- Quick access links to About and Registration
- Copyright and creator credit

## 📱 Responsive Design

- Desktop: Multi-column grids for courses, testimonials, and about sections.
- Tablet: Courses and about sections adapt to two or one column.
- Mobile: All sections stack vertically for easy reading and navigation.

## 🚀 How to Run

1. Clone this repository.
2. Place all images in the `assets` folder as referenced in the HTML.
3. Open `index.html` directly in your browser.
